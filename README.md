# Багряный Собор

Трёхмерные битвы с боссами в духе **Hollow Knight: Silksong**. Веспера,
маленькая свечная моль с золотой рапирой, сражается с хозяевами собора.
Готические залы, мокрый камень, водопады в арках и живой огонёк над её
головой, который гаснет вместе со здоровьем.

Модели, текстуры, анимации и звуковые эффекты генерируются кодом. Музыка —
два трека: «Drowned Cathedral» и «Ash Hunter».

## Как запустить

**Без установки:** откройте файл `play/index.html` в браузере (Chrome, Edge,
Firefox) двойным кликом. Это готовая сборка в одном файле.

**Из исходников:**

```bash
npm install
npm run dev      # запуск с горячей перезагрузкой, http://localhost:5173
npm run build    # сборка в play/index.html
```

Если на слабом ноутбуке игра тормозит, добавьте к адресу `?low` или снимите
галочку «Высокое качество» в меню паузы.

Если вместо сцены чёрный экран (слышна музыка, видны маски и полоса босса),
игра сама переключится в режим совместимости через пару секунд. Его можно
включить вручную, добавив к адресу `?safe=1` (без сглаживания) или `?safe=2`
(без пост-эффектов).

## Управление

| Действие | Клавиатура / мышь | Геймпад |
|---|---|---|
| Движение | WASD / стрелки | левый стик |
| Камера | мышь | правый стик |
| Удар иглой (комбо из 3 ударов) | ЛКМ / J | X / □ |
| Пике вниз в прыжке, отскок от босса | ЛКМ в воздухе | X в воздухе |
| Прыжок / двойной прыжок | Пробел | A / ✕ |
| Рывок (короткая неуязвимость) | Shift / ПКМ | B / ○, RT |
| Связывание (лечение +3 маски за полный шёлк) | E | Y / △ |
| Шёлковый вихрь (3 шёлка) | Q | RB |
| Метательная игла | R | LB |
| Захват цели вкл/выкл | Tab / СКМ | LT, R3 |
| Пауза | Esc / P | Start |

Шёлк копится от ударов иглой: удар по боссу даёт 1 нить, пике — половину.
Полная катушка из 9 нитей позволяет связаться и восстановить 3 маски.

## Боссы

Перед ударом на оружии босса проходит **белая вспышка**. Это сигнал
уворачиваться. На половине здоровья начинается вторая фаза: босс ускоряется
и получает новые приёмы. Если нанести много урона подряд, босс ненадолго
**оглушается**.

### Кармин, Страж Багряного Собора
Огромный рыцарь с копьём.

* **Выпад**: длинный рывок. Уходите рывком вбок.
* **Размах**: копьё низко проходит по кругу. Перепрыгните.
* **Тройной укол**: три выпада подряд, каждый нацелен в вас.
* **Удар древком**: вблизи бьёт в пол, от удара расходится волна.
* **Отскок**: отпрыгивает и сразу атакует издалека.
* **Прыжок с ударом**: падает туда, где вы стоите; ударную волну нужно перепрыгнуть.
* **Багряные шипы**: кристаллы бьют из пола под вами.
* **Восходящий удар**: если долго прыгать у него над головой, бьёт копьём вверх.
* Вторая фаза: серпы-бумеранги, пикирование, связки из выпада в размах.

### Утопленная Настоятельница, Хозяйка Затонувшего Собора
Сгорбленная великанша под кружевной вуалью, с посохом-колоколом. Бой идёт
в затопленном нефе.

* **Колокольный звон**: удар посоха в воду рассылает кольца волн (во второй фазе три). Перепрыгивайте.
* **Удар колоколом**: круг на воде показывает место удара. Уйдите из него.
* **Прилив**: стена воды катится вперёд веером. Перепрыгните или пройдите рывком.
* **Хор утопленников**: из-под воды хватают руки. Не стойте на месте.
* **Погружение**: уходит под воду, рябь охотится за вами, затем она выныривает прямо под ногами.
* **Рукав**: вблизи низко сметает всё рукавом.
* **Водяной столп**: если прыгать над ней, вокруг бьёт гейзер.
* **Слёзы**: с потолка падают тяжёлые капли (во второй фазе багровые).

Сложность «Охотница»: у боссов больше здоровья, и почти любой удар снимает
2 маски.

## Технологии

* [Three.js](https://threejs.org/) + Vite (сборка в один HTML-файл через `vite-plugin-singlefile`)
* Пост-обработка: bloom, ACES-тонмаппинг, цветокоррекция, виньетка, аберрация
* Босс: скелет на двухзвенном IK (руки держат копьё, ноги шагают процедурно),
  плащ считается Verlet-симуляцией ткани, ИИ написан на корутинах
  (генераторах), у каждой атаки есть замах, удар и окно для наказания
* Музыка: у Кармина «Drowned Cathedral» → «Ash Hunter» во второй фазе,
  у Настоятельницы «Drowned Cathedral»; бесшовная петля и кроссфейд; в меню и на паузе звук приглушён.
  Если треки не загрузятся, играет запасная процедурная музыка
* Эффекты: Web Audio, синтез в реальном времени, свёрточный «соборный» ревербератор

```
src/
  main.js     игровой цикл, состояния, экраны
  player.js   героиня: движение, атаки, лечение
  heroine.js  модель Весперы: маска, перья, огонёк, крылья
  boss.js     Кармин: модель, IK, ткань, ИИ, атаки и ловушки
  abbess.js   Настоятельница: модель, вуаль, посох, атаки на воде
  arena.js    соборы (багряный и затонувший): пол, колонны, свет, листва
  water.js    отражающая вода с рябью
  ambient.js  лепестки и пылинки
  fx.js       частицы, искры, дуги ударов, волны, вспышки
  camera.js   камера от третьего лица с захватом цели и тряской
  hud.js      маски, катушка шёлка, полоса здоровья босса
  audio.js    звуковые эффекты и проигрыватель музыки
  music/      треки в MP3
  post.js     пост-обработка
```
